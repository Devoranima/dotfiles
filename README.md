# Arch Linux Dotfiles

This repo contains configuration files for my daily setup.

## Includes
- Neovim (`~/.config/nvim`)
- Hyprland (`~/.config/hypr`)
- Kitty terminal (`~/.config/kitty`)
- Fish (`~/.config/fish`)
## Usage

```bash
git clone https://github.com/Devoranima/dotfiles.git ~/dotfiles
cd ~/dotfiles
cp -r ./.config/* ~/.config
